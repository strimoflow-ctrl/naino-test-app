📏 1. Physical Quantities & Units

A physical quantity is a property of a material or system that can be quantified by measurement. A physical quantity is expressed as: Q = nu (where n = numerical value, u = unit).

The SI System (Systeme International)

There are 7 fundamental (base) units in the SI system:

Supplementary Units

  • Plane Angle (dθ): Radian (rad). Ratio of length of arc to the radius (dθ = ds/r).
  • Solid Angle (dΩ): Steradian (sr). Ratio of intercepted area to the square of radius (dΩ = dA/r2).

🔬 2. Errors in Measurement

Error is the uncertainty in a measurement. True value is generally taken as the arithmetic mean of all readings.

  • Absolute Error (Δa): Magnitude of the difference between true value and measured value. Δai = |amean - ai|
  • Relative Error: Ratio of mean absolute error to the mean value. Δamean / amean
  • Percentage Error: Relative error × 100%
💡 Combination of Errors
  • If Z = A + B or Z = A - B, then maximum absolute error: ΔZ = ΔA + ΔB
  • If Z = AB or Z = A/B, then maximum relative error: ΔZ/Z = ΔA/A + ΔB/B
  • If Z = Ap Bq / Cr, then: ΔZ/Z = p(ΔA/A) + q(ΔB/B) + r(ΔC/C)
🚨 Exam Facts: Least Count Error

Least count is the smallest value that can be measured by the measuring instrument. Least count error belongs to the category of random errors but occurs within a restricted range. It can be reduced by using instruments with higher resolution (e.g., Vernier Calipers vs Metre Scale).

🔢 3. Significant Figures

Significant figures indicate the precision of measurement which depends on the least count of the measuring instrument.

Rules for Counting Significant Figures:

  1. All non-zero digits are significant.
  2. All zeros between two non-zero digits are significant.
  3. If a number is less than 1, the zero(s) on the right of decimal point but to the left of the first non-zero digit are NOT significant. (e.g., 0.002308 has 4 sig figs).
  4. Terminal zeros in a number without a decimal point are NOT significant. (e.g., 123 m = 12300 cm has 3 sig figs).
  5. Trailing zeros in a number WITH a decimal point ARE significant. (e.g., 3.500 has 4 sig figs).
💡 Rounding Off Rules

If the digit to be dropped is 5, look at the preceding digit:
If Odd, increase by 1 (e.g., 2.75 → 2.8)
If Even, leave unchanged (e.g., 2.85 → 2.8)

🚨 Exam Facts: Quantities with Same Dimensions

1. Work, Energy, Torque, Heat: [M1 L2 T-2]
2. Frequency, Angular Velocity, Velocity Gradient: [M0 L0 T-1]
3. Momentum and Impulse: [M1 L1 T-1]
4. Strain, Angle, Solid Angle, Relative Density: Dimensionless [M0 L0 T0]

🛠️ 5. Applications of Dimensional Analysis

Principle of Homogeneity of Dimensions: The dimensions of all the terms on both sides of a physical equation must be the same. Quantities can be added or subtracted only if they have the same dimensions.

Dimensional analysis is used to:

  1. Check the dimensional consistency of equations (e.g., s = ut + ½at2).
  2. Deduce relations among physical quantities.
  3. Convert a physical quantity from one system of units to another (n1[u1] = n2[u2]).
⚠️ Limitations

Dimensional analysis cannot derive the value of dimensionless constants (like π, e, or 2). It also fails if a quantity depends on more than three physical quantities, or if the formula contains trigonometric, exponential or logarithmic functions.
